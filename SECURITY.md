# Security

kubesim is a static site with no backend: no accounts, no server, nothing stored outside your browser. The parts that handle input you didn't type yourself are shared Sandbox links (a cluster snapshot in the URL) and the Lesson and Explainer text the site renders.

## Reporting a vulnerability

Please report it privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. Don't open a public issue.

Useful things to include: the link or steps that trigger it, what happens, and what you expected. You'll get a reply within a week.

Only the latest version on `main` (and the deployed site built from it) is supported.
